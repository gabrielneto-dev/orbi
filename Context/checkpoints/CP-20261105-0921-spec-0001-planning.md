# Session Checkpoint: definição do produto e planejamento da SPEC-0001

## Objective

Transformar a descrição do usuário ("sistema de controle de pragas": OS, propostas, contratos, estoque simples,
cadastro de serviços) numa spec completa, escolher a stack e deixar o desenvolvimento pronto para começar.

## What changed

- `SPEC-0001` criada e levada de `draft` → `specified` → `planned` (spec, plan, tasks, verification).
- `core/` preenchido (overview, goals, constraints, glossary) com o domínio de controle de pragas.
- As duas questions do bootstrap foram respondidas.
- `context_check.py` corrigido para gravar caminhos do catálogo com `/` no Windows.

## Decisions

- `CTX-DEC-20261105-product-scope-saas-pest-control` — SaaS multiempresa para dedetizadoras; MVP sem financeiro e sem offline.
- `CTX-DEC-20261105-tech-stack` — monólito TypeScript (Next.js + PostgreSQL com RLS) em Docker numa VPS.
- Locais à SPEC-0001 (não viram `DEC`): uma spec entregue em fases F0–F7; estoque com razão imutável + saldos materializados; OS geradas de forma síncrona na ativação do contrato.

## Discoveries

- O usuário começou descrevendo um sistema interno; ao dizer que o sistema "precisa suportar todas essas operações" (todos os portes), confirmou que é **SaaS para várias empresas**. Isso revogou a hipótese de empresa única e acrescentou o módulo M0 (plataforma).
- Requisito próprio do domínio trazido pelo usuário: saber quais dispositivos (ratoeiras, porta-iscas) ficaram instalados em cada cliente, por área — virou M7 + plantas com marcações.
- Ambiente desta máquina (Windows): `python3`/`python` no PATH são atalhos da Microsoft Store e não funcionam; os validadores foram executados com outro interpretador instalado, com `PYTHONIOENCODING=utf-8` e `-I`.

## Problems solved

- `context_check.py --rebuild-catalog` no Windows gravava `path` com `\` e acusava "catalog out of date" sem mudança real → corrigido com `as_posix()` (registrado no changelog).
- `sdd_check.py` exige que ACs citem só `REQ-NNN` entre parênteses; referências a regras `BR-NN` foram tiradas dos parênteses.

## Failed approaches worth remembering

- Scripts Bash com vários heredocs longos em pt-BR falharam por erro de parsing (`unexpected EOF`) sem gravar nada; para arquivos grandes, usar as ferramentas de escrita de arquivo.
