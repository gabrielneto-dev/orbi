# Branches de contexto

Branches de domínio criadas em 2026-11-05, quando a implementação da SPEC-0001 (T001–T008) gerou conhecimento específico de área:

- `backend/` — banco PostgreSQL, isolamento entre empresas (RLS), papéis do banco, autenticação. Índice: `backend/_index.md`.
- `infra/` — ambiente local, Docker, dependências; futuramente CI, deploy e backup. Índice: `infra/_index.md`.

Candidata futura: frontend/campo (telas do escritório e do técnico), quando a T017 em diante produzir conhecimento próprio.

Para criar uma branch, siga `Context/README.md` §18 e o template `_meta/templates/branch-index.md`.
Conhecimento transversal continua em `Context/global/`.
